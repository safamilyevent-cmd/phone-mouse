# Phone Mouse — Windows 10/11 + iPhone

Phone Mouse позволяет использовать iPhone как беспроводную мышь и клавиатуру для Windows через общую локальную Wi-Fi сеть.

## Графическая версия Windows

В комплекте теперь предусмотрена Windows GUI-оболочка:
- запуск и остановка серверного процесса;
- автоматическое обнаружение локальных IPv4-адресов;
- шестизначный код сопряжения;
- QR-код со ссылкой для Safari, уже содержащей код;
- копирование ссылки и открытие её в браузере;
- индикация работающего сервера и подключённого iPhone;
- журнал сообщений сервера.

Запустите `PhoneMouse.exe` (или `Run-PhoneMouse.bat`) из распакованного ZIP. Нажмите «Запустить сервер», затем отсканируйте QR-код камерой iPhone. Если на компьютере несколько сетевых интерфейсов, выберите нужный адрес в списке.

## Архитектура

- `PhoneMouse.Desktop`: WinForms GUI, запускает и контролирует отдельный процесс сервера.
- `PhoneMouse.Server`: ASP.NET Core 8, WebSocket и Windows SendInput.
- `PhoneMouse.Server/wwwroot`: интерфейс управления для Safari/PWA.

## Возможности управления

- перемещение курсора, левый/правый клик;
- прокрутка;
- ввод Unicode-текста;
- Enter, Backspace, Tab, Escape, стрелки и сочетания Ctrl+C / Ctrl+V / Ctrl+A;
- переподключение WebSocket после временной потери связи.

## Сборка исходников

Требуется Windows 10/11 x64 и .NET 8 SDK:

```powershell
dotnet restore PhoneMouse.sln
dotnet build PhoneMouse.sln -c Release
```

Автоматическая сборка GitHub Actions публикует автономные Windows x64 GUI и сервер, затем упаковывает их в ZIP. Для релиза создайте тег вида `v1.0.0`.

## Безопасность и ограничения

- Связь работает по HTTP/WebSocket и не шифруется. Используйте только доверенную локальную сеть.
- Не открывайте и не перенаправляйте порт 8765 в интернет.
- Код сопряжения передаётся в query-параметре WebSocket URL; перед production-релизом его следует заменить на обмен токеном в первом сообщении.
- Фильтрация частных IPv4-адресов не заменяет криптографическую аутентификацию.
- Текущая версия рассчитана на одну активную сессию; rate limiting и управление несколькими клиентами не реализованы.
- QR-код открывает страницу Safari с параметром кода. iOS может потребовать подтверждение открытия сайта.
- Графическая оболочка и автоматическая сборка требуют проверки на реальной Windows 10 и iPhone перед широким распространением.

Проект — промежуточная версия, не сертифицированный продукт удалённого доступа.
