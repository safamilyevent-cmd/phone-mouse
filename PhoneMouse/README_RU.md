# Phone Mouse — исходный проект (рабочая доработка v1.1)

Phone Mouse передаёт команды мыши и клавиатуры с веб-интерфейса iPhone на Windows через локальную сеть.

## Что есть в текущем исходном коде
- ASP.NET Core 8 и WebSocket-сервер.
- Генерация одноразового шестизначного кода при запуске.
- Автоматический вывод IPv4-адресов сетевых интерфейсов в консоль.
- Фильтрация входящих запросов по частным IPv4-диапазонам.
- Относительное перемещение мыши, левый/правый/средний клик.
- Прокрутка, Unicode-ввод текста, основные клавиши и комбинации Ctrl+C / Ctrl+V / Ctrl+A.
- Адаптивный тёмный веб-интерфейс, чувствительность курсора и двухпальцевая прокрутка.
- Попытка автоматического переподключения после потери WebSocket.

## Требования для запуска исходников
- Windows 10 x64.
- .NET 8 SDK.
- iPhone и ПК в одной локальной Wi-Fi сети.

Запуск: выполните `start-server.bat`, разрешите доступ в брандмауэре только для частной сети. На iPhone откройте один из адресов, напечатанных сервером, и введите код сопряжения.

## Важные ограничения этой версии
Это промежуточная рабочая доработка исходников, а не готовый установочный продукт.
- QR-код, полноценное графическое Windows-приложение, системный трей и установщик ещё не реализованы.
- Код сопряжения передаётся в query-параметре WebSocket URL. Это удобно для прототипа, но может попадать в диагностические журналы; перед выпуском нужно заменить на авторизацию первым сообщением.
- HTTP/WebSocket не шифруются. Фильтрация частных IPv4-адресов не заменяет криптографическую защиту.
- Ограничение одной активной сессии и полноценный rate limiting ещё требуют реализации.
- Автоматическое переподключение зависит от того, что код сопряжения ещё действителен и сервер доступен.
- PWA не гарантирует установку/автономную работу через обычный HTTP на iOS.

Не публикуйте порт 8765 в интернет, не настраивайте проброс портов и не используйте недоверенные Wi-Fi сети.

## Сборка
На Windows с установленным .NET 8 SDK из каталога `PhoneMouse.Server`:

```powershell
dotnet publish -c Release -r win-x64 --self-contained true /p:PublishSingleFile=true
```

Проверка на настоящей Windows 10 и iPhone обязательна перед распространением. В текущей среде Windows/.NET SDK/iPhone нет, поэтому готовая EXE-сборка и установщик не заявляются.
