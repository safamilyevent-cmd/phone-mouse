# Phone Mouse

Wireless iPhone mouse and keyboard for Windows 10 over the local Wi-Fi network.

## Source
The application source is in `PhoneMouse/`. The Windows x64 build and ZIP release are automated by `.github/workflows/build-windows.yml`.

## Build
Push to `main` to run CI. Push a version tag such as `v1.0.0` to create a GitHub Release with the Windows x64 ZIP and source ZIP.

See [Russian project instructions](PhoneMouse/README_RU.md) for setup and limitations.
